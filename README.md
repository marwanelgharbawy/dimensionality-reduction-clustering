# Dimensionality Reduction & Clustering Analysis

### 1. Dimensionality Reduction
- **PCA:** Full eigenvalue decomposition, explained variance ratio, and reconstruction error.
- **Autoencoder:** Fully connected network with backpropagation, mini-batch GD, L2 regularization, and customizable activation functions.

### 2. Clustering
- **K-Means:** Support for K-Means++ and random initialization.
- **GMM (Gaussian Mixture Models):** Full EM algorithm supporting Full, Tied, Diagonal, and Spherical covariance matrices.
